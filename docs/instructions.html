🚀 Getting Started

Installation

  1. Download the app from the download button on the home page
  2. Install by running the setup file
  3. Launch Quire Desktop from your desktop or Start menu
  4. Sign in using the OAuth authorization when prompted

First-Time Setup

When you first launch the app, you'll be taken through a simple setup:

  1. Click “Authorize with Quire” in the welcome window
  2. Sign in to your Quire account in your browser
  3. Allow Quire Desktop to access your account
  4. The app will automatically sync your projects and tasks

🖱️System Tray Integration

The app runs quietly in your system tray:

  • ● Green = Connected
  • ● Yellow = Connecting
  • ● Red = Issue

Right-click for quick menu access

Keyboard Shortcuts

  • Ctrl + Shift + Q — Show/hide the app window
  • F5 or Ctrl + R — Refresh the current view
  • Ctrl + Shift + R — Force reload

⚙️ Settings & Customization

Access Settings

Click the gear icon in the tray menu or use the settings option to customize:

Notification Preferences

  • Enable/disable specific notification types
  • Only my tasks: Filter to show only tasks assigned to you
  • Morning digest time: Set when you want your daily summary
  • Lead time: Choose when to get reminders (at time, 5 min, 15 min, 30 min, 1 hour before)
  • Overdue strategy: How often to remind about overdue tasks

Do Not Disturb

Set quiet hours when you don't want to be interrupted:

  • Enable DND mode
  • Set start time (e.g., 10:00 PM)
  • Set end time (e.g., 8:00 AM)

General Settings

  • Start minimized: Launch the app in the system tray
  • Home URL: Set your default Quire workspace
  • Global shortcut: Customize the keyboard shortcut

🛠️ Troubleshooting

Not receiving notifications?

  • Check that notifications are enabled in Settings
  • Ensure Windows notifications are allowed for Quire Desktop
  • Verify you're signed in (green dot in system tray)

App won't connect?

  • Check your internet connection
  • Try “Force Sync” from the tray menu
  • Sign out and sign back in

Notifications not clicking through?

  • Make sure Quire Desktop is your default handler
  • Try closing browser tabs with Quire open
⚠️ Still having issues?
Try Ctrl + Shift + R for a force reload, or restart the app.
