v3.8.7

What's new in this release

  • ✓Reload works in every keyboard layout. With a non-Latin layout active, Ctrl+Shift+R used to reach Quire instead of the app — and Quire could read it as “complete this task”. The shortcuts now follow the physical key.
  • ✓Updates straight from GitHub. The app now checks GitHub Releases for new versions — no server of ours in between, nothing that can expire or go offline.
  • ✓Notifications keep you in Today. Opening a task from a toast never bounces you into the project view any more, however slow the page is to render.
  • ✓Follow without the noise. A new switch silences tasks where you are only a follower — only what is assigned to you or created by you gets through.
  • ✓A morning digest you can act on. Clicking it opens the exact list of tasks it announced — grouped, timed, each one a link. The list stays open above the app so you can work straight through it.
  • ✓Your own view bar. Save any Quire view — including a My Tasks sublist — as a one-click button in the title bar, with an icon. Jump straight to it from anywhere, no matter which view you are browsing.
  • ✓A calmer title bar. The page title can be hidden in Settings, leaving the room to your saved views.
  • ✓Notification clicks stay put. Opening a comment from a notification no longer bounces you into the project view a few seconds later — you stay in Today, right where the comment is.
  • ✓"Only my tasks" honored again. Stale unfiltered webhook subscriptions from old versions are cleaned up automatically — no more toasts about tasks you're not part of.
  • ✓Windowed sync. The app now fetches only tasks that can actually notify — everything overdue plus the next 7 days. An order of magnitude less traffic, faster startup and refreshes.
  • ✓Subtasks finally sync. Dated subtasks were invisible to sync before — expect a one-time batch of overdue reminders right after updating, then the normal daily rhythm.
  • ✓Right-click Copy fixed for good. Selected text is captured the moment you right-click and written straight to the clipboard.
  • ✓Leaner under the hood. Server-side proxy fix (query parameters now reach the Quire API) and dead code removed.
Get started

Up and running in under a minute

  1. Click Download for Windows to grab the installer.
  2. Run the installer and follow the short setup wizard.
  3. Launch Quire Desktop and sign in with your Quire account via secure OAuth.
  4. Allow notifications when prompted — and you're done.
  • ✓ Windows 10 or Windows 11
  • ✓ Active internet connection
  • ✓ A Quire account (free or paid)
  • ✓ ~200 MB of free disk space
